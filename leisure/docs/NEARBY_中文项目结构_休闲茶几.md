# NEARBY｜跟着休息走的升降茶几

更新日期：2026-10-10
英文标题：**NEARBY — Bring your break with you.**
主稿：[Figma 最新六面](https://www.figma.com/design/ApoghdbZoRBlbBcDctaMXf/Untitled?node-id=383-3293)

## 项目定位

- **Who｜给谁用**：希望少搬东西、轻松享受休息的年轻人。“懒”转译为减少琐碎搬运与重复布置，而非能力不足。
- **Where｜在哪里用**：家里的客厅、同层封闭阳台，以及旅居时的临时室内住所。
- **When｜什么时候用**：喝茶、阅读、放松；想从阳台换到客厅，或换一种坐姿时。
- **What｜提供什么**：可跟随移动、停驻后可调节高度的茶几，把茶杯、茶壶或保温杯、书和手机放在一起。
- **核心问题**：人可以轻松换一个休息地点，茶具和桌面却通常需要分批搬运、重新摆放；不同座位也需要不同的桌面高度。
- **设计命题**：让一次完整的茶歇随人换位置，再停稳、调高或调低、继续休息。

英文概述：

> NEARBY is a followable, height-adjustable tea table for young adults who want effortless downtime. Tea, a book and a phone stay together as the user moves from an enclosed balcony to the living room. The wheeled cabinet follows, parks and adjusts its surface to the next seat.

## 六面结构与正文内容

### 01｜Background + Everyday Leisure Context

左侧：年轻人在阳台喝茶的概念场景。延续原封面比例、NEARBY 标题、工具及关键词位置。中间保留简介与设计目标；右侧沿用两栏背景版式。

**简介**：把喝茶、阅读和放松所需的小物放在可移动表面上，让用户从阳台走到客厅时，茶几可以跟随，并在新的座位旁停驻。

**设计目标**：减少打断休息的搬运与重新布置。FOLLOW 开启一段室内跟随，STAY 停止，HEIGHT 在停稳后调整台面高度。用户决定何时换位置。

右侧内容：
1. 什么是可跟随茶几：移动、升降、停驻使用。
2. 场景：家庭／短住；阳台／客厅；喝茶／阅读／休息。
3. 当前情境：搬东西、移动桌子、重设座位旁的摆放。
4. 机会方向：可控跟随、适配坐姿的台面、清楚的状态。
5. 特征：休息物品一起移动；适应不同座位；少一点重复布置。

原老年照护统计已替换为场景关键词。右侧“机会方向”图是设计示意，不是调查数据。

### 02｜Scenario Research + Current Leisure Journey

以情境研究与待观察问题组织，不声称已完成实地访谈。

左栏三组问题：
1. **人与物品**：杯子、书和手机需要一起带走；饮品需要稳定的表面。
2. **人与空间**：改变休息地点涉及室内路线、门口和重新落座。
3. **人与家具**：希望桌子跟来、适配座位，并能随时停止。

用户招募方向：
- 家中休闲者：喝茶、读书，在多个座位间换位置。
- 短住旅居者：在临时住所中建立简单的休闲布置。
- 共享居住者：需要可控移动和明确的个人使用会话。

三条研究问题：
- 杯子、书和手机能否一起移动，减少来回取物？
- 更换舒适或光照地点时，茶几是否适合跟随？
- 停驻后的可调台面是否适应沙发、椅子与放松坐姿？

**现状旅程假设**：准备 → 携带 → 落座 → 换位置 → 返回取物 → 重新布置 → 调整姿势／高度 → 继续休息。

照片是不同活动的情境说明，不是同一参与者的连续记录。情绪曲线是待检验假设，没有填写量化效果或访谈结论。

### 03｜Design Concept + Technical Research + Concept Development

**设计概念**：Your tea break, on the move.

四格整合：核心命题；年轻人／直接控制；个人 App；茶几与室内地点。保留复杂的双色功能图标，将旧 HELP 图形改为升降机构，将眼镜图形改为茶杯与书。

三项目标：
1. 把一整套茶歇物品带在身边。
2. 在室内休闲地点之间可控地移动。
3. 停驻后调节表面，适应此刻的座位。

技术研究保持三段式：技术原理 → 功能结构 → 外部技术应用参考。
- 本地视觉：摄像头、STM32、本地人脸匹配；身份识别与连续跟踪分别验证。
- 四点电动升降：四根 A2 电机推杆；行程协调、停止和载物稳定性待测。
- 跟随与手机控制：创作者说明底部电动轮可以跟踪人；新交互提供 FOLLOW／STAY／HEIGHT。

当前选型记录为 STM32H743 + OV2640。固定 ROI 人脸匹配核心代码在电脑侧测试，板端测试仍待完成，不把代码演示写成已完成整机自主跟随。

功能结构：摄像头 → STM32 本地匹配与控制逻辑 → 驱动 → 四根推杆／电动轮；手机界面提供请求与状态。

外部图分别来自 ST、Bansbach、Pololu，用于原理调研，不能作为本项目对应品牌部件、A2 确切型号或已完成性能的证据。

右侧概念关系：识别选定用户 + 休息地点 + 坐姿 → 休闲需求 → 可见反馈与简单控制。优势用“待验证”表达：连续休息、可控移动、减少搬运、舒适高度、简单设置。

### 04｜System + Indoor Places

系统由年轻使用者、茶几、直接操作、个人 App、茶歇物品与房间设置组成。移除家属、照护者与求助传递的服务故事。

地点：
- **A｜客厅沙发**：停在座位旁，再调整高度。
- **B｜封闭阳台椅**：与客厅同层；使用前检查门口门槛。
- **C｜充电位置**：清楚、空闲的停放点。

三层轴测地图延续原版线稿和暖色：
1. 室内休闲场地。
2. 个人保存的停放点。
3. 路线与禁入边界。

已把原卧室 B 点改为阳台座椅，平面图与三层图一致。地图、保存地点与禁入区域是交互提案及模拟，不声称原型已实现 SLAM、自动建图或可靠导航。

### 05｜Device + Personal App

实体：延续已有箱柜、四点升降平台、带边托盘与移动底座。新增茶杯、书、手机和带盖杯；按钮统一为 FOLLOW／STAY／HEIGHT。

个人 App 内容：
- 配对当前跟随用户。
- 开始、停止和查看移动状态。
- 停驻后调整高度。
- 复核室内地图，保存沙发、阳台与充电点。
- 保存茶歇场景与座位高度预设。
- 查看电量与设备连接状态。

示例 620 mm／450 mm 为界面原型值，不作为实物已核验的升降范围。原来的 Find／Family／Remote 导航改为 Height／Places／Control，并替换了对应的物品搜索图标。

页面保留技术结构、实体说明和现有高保真界面的布局。模型渲染与生成场景是概念可视化；实际 Blender 工作区截图保留为制作过程。

### 06｜Prototype + Leisure Scenario

保留真实制作照片、结构图和原始装置试作，展示柜体装配、升降机构与接线过程。右侧展示“阳台走向客厅，茶几跟随”的年轻人场景模拟。

**反思**：原型让“从一个房间换到另一个房间休息”成为可以测试的交互问题。下一步应对比普通边几、手动移动茶几与跟随茶几，记录搬运次数、布置耗时、停止位置、饮品稳定性与使用者对移动控制的理解。

## 个人交互流程

1. 放好物品，复核室内路线与当前设备状态。
2. 配对／确认当前使用者。
3. 明确选择 FOLLOW，开启一次跟随会话。
4. 换到新的休息地点。
5. 选择 STAY，确认已停止。
6. 停驻后选择 HEIGHT，调节台面并可保存为座位预设。
7. 取用茶杯、书与手机，继续休息。
8. 需要换位置时，再次开启 FOLLOW。

异常分支：目标不确定、连接异常或路线不清楚时暂停；用户确认后重新开始。高度变化发生在停驻状态。载热饮时的稳定性与控制逻辑需要实际测试；没有在作品集中填入未经测量的安全参数。
