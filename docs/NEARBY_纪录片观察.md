# NEARBY｜第二面左侧：纪录片观察

这部分是二手资料研究，英文标题保留 Field Research，并以 Documentary review 明确方法。尚未开展访谈、入户观察或产品效果测试。

## 研究材料

主要案例为 Deborah Hoffmann 的《Complaints of a Dutiful Daughter》（1994，44 分钟）。本次核对发行平台公开字幕、PBS 公开预告片和公开宣传配图，没有把预告片当作完整影片观看记录。

- [Docuseek 公开字幕](https://docuseek2.com/wm-cdd)
- [PBS 28 秒公开预告片](https://www.pbs.org/video/pov-complaints-dutiful-daughter-trailer/)
- [Swarthmore 影片介绍与宣传图片](https://femfilm.swarthmore.edu/films/801/)
- [Women Make Movies 发行资料](https://www.wmm.com/catalog/film/complaints-of-a-dutiful-daughter/)

## 可追溯的观察

| 正片字幕时间 | 这个家庭的经历 | 可探讨的设计问题 |
|---|---|---|
| 06:25–08:43 | 便条逐渐累积，已完成的牙医预约仍引发再次前往。 | 如何让提示清楚表达“现在需要做什么”和“已经完成什么”？ |
| 09:04–10:45 | 与助听器有关的事项引发重复留言。 | 怎样保留容易理解的共享确认状态？ |
| 10:52–11:22 | 通话中离开电话寻找便条，可能忘记寻找目标。 | 能否减少任务中断和寻找过程？ |
| 12:00–12:25 | 饼干盒藏在家中不同位置，旧票根又被用于尝试再次观看演出。 | 熟悉物品的位置与新旧提示如何区分？ |
| 12:54–13:06 | 女儿描述日常时间越来越多地用于处理这些情况。 | 能否减少反复解释，同时保留人与人的支持？ |

这些经历涉及记忆、提示解释、任务连续性和照护沟通，不能直接推断当事人行动不便，也不能推广为所有认知症长者的共同表现。

## 与 NEARBY 的联系

把熟悉物品保持在固定布局、提供单一当前提示、允许家庭成员共同确认状态，是由资料提出的设计假设。移动柜是否更容易使用、是否会破坏固定位置线索、停靠是否妨碍通行，需要后续与长者及照护者共同测试。
