# NEARBY｜用户研究与体验结构

本次依据提供的 User Research & Insights 参考重排第二面对应区域。字体沿用 IBM Plex Sans，颜色沿用暖橙、米白和深灰。

## 上方三栏

1. 用户分类：认知症长者、家庭照护者、照护专业人士。这里描述拟邀请参与共同设计的角色，不虚构年龄、访谈人数或已经获得的反馈。
2. 问题归纳：找到熟悉物品、在任务中保持目标、知道何时及如何求助。
3. 认知要求：以可能的感受与任务要求示意说明需要进一步研究的关系，不把它写成已经验证的临床因果模型。

## 下方八阶段体验旅程

| 阶段 | 情境中的疑问 | 需要理解或记住什么 | 行动 |
|---|---|---|---|
| 察觉需求 | 我刚才想做什么？ | 保持目标 | 察觉日常需要 |
| 寻找 | 东西放在哪里？ | 回忆位置 | 寻找物品 |
| 移动 | 为什么来到这个房间？ | 跨房间保持目标 | 在房间之间移动 |
| 识别 | 这是我要找的吗？ | 辨认正确物品 | 核对熟悉线索 |
| 使用 | 下一步是什么？ | 理解下一步 | 继续日常活动 |
| 放回 | 应该放回哪里？ | 回忆固定位置 | 归还物品 |
| 求助 | 谁可以帮助我？ | 表达需求 | 请求支持 |
| 继续 | 我们能一起完成吗？ | 在支持下恢复任务 | 一起完成任务 |

旅程为综合情境假设；疑问不是参与者原话，情绪曲线没有量化分数，也不代表实际测量。图中照片为 Pexels 情境照片及 PBS 纪录片资料，人物并非项目受访者。
